Optional iNaturalist sign-in

Public-only mode. Sign-in is optional.

While signed in, your own precise/private locations are used for previews and metadata, including EXIF GPS where missing. Sharing the resulting images can reveal locations hidden on iNaturalist. Existing GPS is still kept; turn off locality and GPS syncing if you do not want those fields written. Templates can also include location data.

Set up and sign in with your own OAuth application

Register an application at iNaturalist OAuth applications, using the callback URL below. Sign-in takes place on iNaturalist; never enter your iNaturalist password here. Save any other setting edits before leaving this page.

If selected, the client ID and secret are stored outside your normal config and browser storage: in a plaintext file restricted to your user account on macOS and Linux, or in Windows Credential Manager. Leave the secret blank to reuse saved credentials for the same client ID. Unchecking this option removes any saved credentials when you start sign-in. Access tokens are never saved: sign in again after restarting. You can also fill these fields using a password manager. Use this app only on your own computer.

This check loads all public observations for the entered username and may take a while. It does not download photos or change files.

Observation metadata

Observation links and IDs are always written so photos can be recognized on later runs. Choose everything else below. Switching a category off leaves its existing metadata untouched.

Existing EXIF or XMP GPS coordinates are kept. Public-only mode uses approximate coordinates for obscured locations and skips locations with no available coordinates. Signing in uses your own private coordinates when available.

Step 3 of 5

Review your matches

Choose a date in the sidebar. Compare the iNaturalist reference images with local candidates; click a candidate to select or deselect it. Selected images have a blue border. Corrections are kept for this session, but files are not changed yet.

What should I check?

Start with days marked as needing attention. Check suggested matches, select the correct photos and use Search whole library if none are right. You can leave observations unmatched and continue whenever you are satisfied.

Already tagged photos may need a metadata refresh. Deselecting a previously tagged photo schedules removal of this app's observation metadata, but keeps its GPS coordinates and other keywords. Version siblings are selected together when version grouping is enabled.
